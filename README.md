# Rahul Gupta - Portfolio Website

A modern, high-performance personal portfolio showcasing full-stack development work, case studies, technical skills, and experience.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion
- **Icons**: Lucide Icons
- **Bundler & Dev Server**: Vite

## Getting Started

### 1. Install Dependencies

You can install dependencies using **pnpm** (recommended for workspaces) or directly in the portfolio directory with **npm**:

#### Option A: Using pnpm from the root
```bash
pnpm install
```

#### Option B: Using npm inside the portfolio folder
```bash
cd artifacts/rahul-portfolio
npm install
```

### 2. Run the Development Server

#### From root (with pnpm):
```bash
pnpm dev
```

#### From `artifacts/rahul-portfolio`:
```bash
cd artifacts/rahul-portfolio
npm run dev
```

The application will be available at `http://localhost:5173`.

### 3. Build for Production

```bash
pnpm build
```
Or:
```bash
cd artifacts/rahul-portfolio
npm run build
```
